#  AI Sales Agent

A full-stack AI-powered Sales Agent system built with **FastAPI** and **React**, designed to automate:

- Customer interaction
- Lead capture
- Booking flows
- Backend workflows via **n8n integration**

---

## Tech Stack

### Backend
- FastAPI
- Python
- n8n

### Frontend
- React
- Vite
- Tailwind CSS

---

- **Intent Detection**  
  `/webhook/intent`

- **Lead Scoring**
